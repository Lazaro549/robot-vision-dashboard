Architecture

Perception pipeline

Camera / Video→Preprocess→COCO-SSD→Tracking→Telemetry
  1. Capture frames from a webcam or local video.
  2. Run object detection with a browser-loaded COCO-SSD model.
  3. Match detections between frames using centroid distance.
  4. Expose latency, FPS, confidence, object count, and simulated robot telemetry.
Engineering note: this demo uses real browser-side inference. Robot telemetry is intentionally simulated; the README documents the boundary between real perception and simulated robotics data.
